Rclone Pribadi

A personal, non-commercial tool for backing up and syncing files with my own Google Drive account.

What this app does

Rclone Pribadi is the OAuth client used by my own installation of rclone, an open-source command-line program for managing files on cloud storage. It lets me copy, back up and synchronize files between my own computer and my own Google Drive account.

How it uses Google Drive

When I sign in, the app asks for permission to:

  • list, read, create, modify and delete files in the Google Drive account I sign in with, so that backups and synchronization can work;
  • read file metadata (such as names, sizes and modification times), so that unchanged files are not transferred again.

Files are transferred directly between my computer and Google Drive. This app does not run any server and does not collect, store or forward Google user data to anyone else.

Who uses it

The app is used only by its owner, and possibly a few people known personally to the owner. It is not offered to the general public, and it has no commercial purpose.
